# 할 일 관리 앱 PRD

## 1. Why - 목적
- 할 일을 생성·수정·삭제하고 상태(todo/doing/done)로 관리
- 드래그 앤 드롭으로 상태를 빠르게 변경
- 일일 / 주간 / 1년 목표를 한 곳에서 관리

## 2. Who - 타깃 사용자
- 개인 할 일을 상태별로 관리하려는 사용자
- 단기 할 일(일일·주간)과 장기 목표(1년)를 함께 관리하려는 사용자
- 칸반 방식의 시각적 관리에 익숙한 사용자

## 3. User Flow
1. 앱 진입 → 기간 탭 선택 (일일 / 주간 / 1년)
2. 선택한 기간의 칸반 보드 확인 (todo / doing / done 컬럼)
3. 할 일 생성 → 제목 입력 → 기간 지정 → 저장 (기본 상태: todo)
4. 할 일 카드 선택 → 내용 수정 → 저장
5. 카드를 다른 컬럼으로 드래그 앤 드롭 → 상태 변경 및 저장
6. 할 일 삭제 → 확인 → 목록에서 제거

## 4. 기능 요구 사항

### P0 - 핵심 기능
- **할 일 CRUD**
  - 생성: 제목(필수), 설명(선택), 기간 유형(일일/주간/1년), 기간 값
  - 조회: 기간·상태별 목록
  - 수정: 제목, 설명, 기간, 상태
  - 삭제: 확인 후 삭제
- **상태 관리**
  - 상태값: `todo` / `doing` / `done`
  - 생성 시 기본값: `todo`
  - 상태 변경 즉시 저장
- **드래그 앤 드롭**
  - 컬럼 간 이동 시 상태 변경
  - 이동 중 드롭 위치 시각 표시
  - 저장 실패 시 원래 위치로 롤백
- **기간 구조**
  - 기간 유형: 일일 / 주간 / 1년 목표
  - 기간 값: 날짜(일일), 주 시작일(주간), 연도(1년)
  - 기간 탭 전환 시 해당 기간 보드 표시
  - 이전/다음 기간 이동
- **데이터 모델**
  - Task: `id`, `title`, `description`, `status`, `period_type`, `period_value`, `order`, `created_at`, `updated_at`

### P1 - 추가 기능
- 같은 컬럼 내 드래그 앤 드롭 순서 변경 (`order` 저장)
- 기간 간 연결: 일일 → 주간 → 1년 목표 상위 항목 지정 (`parent_id`)
- 기간별 진행률 표시 (done 수 / 전체 수)
- 미완료 할 일 다음 기간으로 이월
- 키워드 검색 및 상태 필터
